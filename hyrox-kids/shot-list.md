# Shot list — HYROX for kids promo (print this for the day)

Film in 9:16, 1080x1920. Get each shot for 3–5 seconds; only 1–2s
will be used. Tick off as you go. Do not film any child without
their parent's written consent.

## Arrival
- [ ] Wide: family walking under entrance arch, backs to camera
- [ ] Close: backpack / kit
- [ ] Wide: arena, first look

## Registration
- [ ] Close: wristband going on
- [ ] Close: number written on arm
- [ ] Close: shoes
- [ ] Medium: parent + child at desk

## Sign prep
- [ ] Table: making a supporter sign, markers, hands
- [ ] Close: finished sign

## Warm-up
- [ ] Lunges
- [ ] High-five with another child
- [ ] Group line-up
- [ ] Plank / stretch
- [ ] Running drills

## Race — stations (one shot each, side-on)
- [ ] Running
- [ ] SkiErg
- [ ] Sled push
- [ ] Rower (Concept2)
- [ ] Farmer's carry
- [ ] Medicine-ball squat

## Mid-race breather
- [ ] Hydration: drinking water, smile

## Finish
- [ ] Running under finish arch
- [ ] Tired-but-happy face (only if the child is happy to be filmed)
- [ ] Hug from parent — let this run 3–4s, do not cut it short
- [ ] Supporter sign in frame

## After
- [ ] Check-out: staff checking wristband
- [ ] Close-up: hands adding finisher patch / medal to a bag
- [ ] Wide: family walking away together, backs to camera (HOME TIME)

## Audio / notes
- [ ] One licenced music track chosen, 58s, upbeat
- [ ] Ambient sound recorded (crowd, feet) for under the music
- [ ] Consent list completed, parent has seen the final cut
